Accessibility Statement

Last updated August 13, 2026

InCyTrade wants this site usable by everyone, including people using a keyboard alone, a screen reader, magnification, or who need reduced motion. This page states the standard we build to, what is implemented, and what is scheduled next.

Conformance target

We build to WCAG 2.1 Level AA. That standard underlies each jurisdiction this site is meant to work for: it's the technical basis for EN 301 549 (the EU standard behind the European Accessibility Act), it's what Israeli Standard 5568 is built on (the standard referenced by Israel's accessibility regulations under the Equal Rights for Persons with Disabilities Law), and it's the benchmark U.S. courts and the DOJ most commonly reference for ADA Title III compliance, even though no single binding federal technical rule yet covers private commercial websites the way it does U.S. state and local government sites.

What's implemented

  • Semantic landmarks throughout (header, nav, main, footer) and a single, logically ordered heading hierarchy per page.
  • A "Skip to content" link, visible on keyboard focus, at the top of every page.
  • Full keyboard operability - every interactive element (navigation, the mobile menu toggle, links, buttons) works without a mouse, including closing the mobile menu with the Escape key.
  • A visible focus indicator on every focusable element - nothing here removes the browser's focus outline without replacing it.
  • Text and UI color combinations checked against WCAG AA contrast thresholds (4.5:1 for normal text, 3:1 for large text), for both the default and hover states we use.
  • No content relies on color alone to convey information that isn't also stated in text.
  • Text reflows and stays readable at up to 200% browser zoom. Nothing disables pinch-to-zoom.
  • Motion respects prefers-reduced-motion - the scroll-triggered reveal effect and smooth-scrolling are both disabled for anyone whose OS requests reduced motion.
  • No flashing, strobing, or auto-playing media anywhere on the site.
  • Anchor links account for the sticky header, so a jumped-to section never lands hidden underneath it.

How this is verified

Every page is checked automatically against WCAG 2.1 A and AA rules on each change, and currently passes with no violations reported. Automated testing catches a meaningful share of issues but not all of them, so it runs alongside manual keyboard and zoom checks at build time.

Ongoing work

  • A structured manual review with screen readers (NVDA, JAWS and VoiceOver) is scheduled, alongside a third-party conformance audit.
  • A Hebrew version of this site is planned for Israeli visitors who would prefer one.
  • Documents distributed separately from this site are reviewed for accessibility on their own schedule.

Reporting a barrier

If you hit an accessibility problem anywhere on this site, tell us - email support@incytrade.com with the page and what happened. We will acknowledge your message and work to resolve genuine barriers promptly. If a fix will take time, we will tell you what the interim alternative is.

Note on this document. This reflects what is implemented in this site's code as of the date above, rather than a template claim of full conformance. It is revised as the site changes and as the reviews listed above are completed.
